# Option 2 — Programming Quiz

### The idea:

```text
- To still create a coding game but avoiding complications and sticking to the subject of Trancendece, while not losing the essense of what we wanted to do at the begining.
```

### The solution:

```text
- To create a time based quiz game. Each player has a timer that starts to run out, when you anser a question, you get some extra time. If you decide to skip an excerises, this substracts adds time to your opponent. Making a mistake on your submit substracts time from you.
- Fill-in the missing code, Multiple choice, or Expected output could be happening at the same time in a single game.
- The winner is whoever ansered more questions before both times run out. We can even think about a point based system if we want to give more rellevant to fill the code and less relevance to the multiple choice, but that we can see.
```

This option keeps the competitive idea but makes the project more simple.

We would keep one frontend, one backend, and one database. No LLM or separate C runner.

This last 2 are complicated to achieve, and they give no points according to the subject.
