# Choosing our extra points

Our starting plan gives us **12 possible points**. We want **15**, so we need three more. We can choose from these options.

| Feature and points | How we could build it |
| --- | --- |
| **Shared design — 1 point** | Create at least 10 reusable pieces, such as buttons, forms, and cards, with matching colours, fonts, and icons. |
| **Two extra browsers — 1 point** | Make every feature work in Firefox and Edge, alongside Chrome. Test them and document any differences. |
| **Watch matches — 1 point** | Let people watch ongoing games, with live timers and scores, without joining as players. |
| **Question search — 1 point** | Add a question library with search, filters, sorting, and separate pages of results. |
| **Import/export questions — 1 point** | Load batches of questions from files, check their contents, and export them as JSON and CSV. |
| **Player rewards — 1 point** | Add at least three systems, such as achievements, levels, and a leaderboard. Save progress and show players what they earn. |
| **Statistics and history — 1 point** | Show previous opponents, dates, results, player statistics, achievements, progress, and rankings. |
| **Three languages — 1 point** | Translate all player-facing text into three languages and add a language selector. |
| **Game settings — 1 point** | Add special abilities such as hints, visual themes, adjustable game settings, and a default mode. |
| **Status and backups — 1 point** | Show whether the app is working, save automatic backups, and document how to restore them. |
| **Tournaments — 1 point** | Let players register, arrange their matches, show a tournament bracket, and advance winners. |
| **Three or more players — 2 points** | Allow at least three people in one match, with fair rules and live updates for everyone. |
| **Full user profiles — 2 points** | Let players edit profiles, upload an avatar, add friends, and see who is online. Provide a default avatar. |
| **Chat and friends — 2 points** | Add private messages, viewable profiles, and a friends list with add/remove actions. |
| **Two-step login — 1 point** | Require a second verification code when logging in, with setup, disabling, and account recovery. |
| **Personal data controls — 1 point** | Let users request and download their data, confirm deletion, and receive confirmation emails. |
| **Notifications — 1 point** | Notify users about relevant actions whenever information is created, changed, or deleted. |
| **File uploads — 1 point** | Support images and documents, check file type and size, control access, and provide previews, upload progress, and deletion. |
| **Offline app — 1 point** | Make the website installable and let players use a practice mode without internet. |
| **Right-to-left language — 1 point** | Support a language such as Arabic, including mirrored page layouts and switching between text directions. |
| **Activity dashboard — 1 point** | Show players their activity over time, such as sessions played and question types attempted. |
| **User roles — 2 points** | Add roles such as admin and player. Let admins manage users, and check which actions each role can perform. |
| **Groups — 2 points** | Let people create, edit, and delete groups, manage members, and create, view, and update shared content inside them. |
| **Interactive charts — 2 points** | Display live statistics with interactive charts, date filters, and downloadable reports. |
| **Full accessibility — 2 points** | Meet WCAG 2.1 AA requirements, including keyboard controls, screen readers, and other assistive tools. |

## Possible combinations

- **Design + extra browsers + spectators:** 12 + 1 + 1 + 1 = **15**
- **Search + import/export + design:** 12 + 1 + 1 + 1 = **15**
- **Three or more players + spectators:** 12 + 2 + 1 = **15**
- **Statistics/history + rewards + design:** 12 + 1 + 1 + 1 = **15**

For **16 points**, add another complete 1-point feature.

These choices remain open for the team. Each module must meet its full subject requirements to count, even where features overlap.
